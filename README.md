# 灵素图谱 · SpiritCodex

本项目仅保留 `main` 分支，作为本地当前版本与 GitHub 的统一基线。HTML5 游戏源码、美术资源、Unity 工程及相关文档均纳入版本管理；依赖、浏览器缓存和测试输出保留在本地。

## 启动游戏

下载或克隆完整项目后，Windows 用户双击根目录的 `start-game.cmd`，在浏览器中点击「启动游戏」。无需安装 Unity、Node.js 或其他依赖。

其他系统直接用浏览器打开根目录的 `index.html`，点击「启动游戏」进入现有 HTML5 游戏。入口使用相对路径，也可通过静态服务器访问；支持中文及带空格的项目路径。

游戏本体位于 `playable/spirit-codex.html`。入口不会更改游戏存档；浏览器存储规则与现有游戏保持一致。

## 启动验收

1. 双击 `start-game.cmd`，确认默认浏览器打开启动页。
2. 点击「启动游戏」，确认进入游戏标题页，再使用游戏内的开始按钮进入玩法。
3. 用浏览器返回启动页，按 Tab 选中「启动游戏」，按 Enter 确认仍可进入游戏。
4. 在 360px 宽的窗口下确认中文完整、按钮可点击、没有横向滚动。
5. 将完整项目放在包含中文和空格的目录下，重复第 1、2 步。
