# v14：技能预览、合击接管与 Boss 战术窗口

日期：2026-09-06。入口 `playable/spirit-codex.html`。本轮只完善“看懂技能 → 判断时机 → 实际施放 → 查看结果”这一条战斗循环，并以第三波混沌元素验证；不新增货币、破韧条或独立模拟战斗引擎，不改 Unity 与既有美术素材。

## 技能：先看目标，再确认操作

- 手动回合悬停或键盘聚焦技能时，在战场标出作用范围。文字说明不在悬停时插入，避免小屏按钮被挤动、点击落空。
- 单体攻击/治疗保持“选技能 → 选敌人/存活正式队友”。目标按钮的悬停/聚焦、Canvas 指向共用预览；不可对敌方治疗，也不能把召唤物选为正式队员治疗目标。
- 群攻、群体治疗、护盾、增益、净化与召唤改为“选技能 → 查看范围 → 确认施放”。取消不推进回合、不扣能量、不进入冷却；确认仍调用原技能结算及 v11 动作管线。
- 实线表示指定作用范围，虚线表示待选、随机连锁或概率附加目标，并非保证命中。分清敌方伤害、己方治疗/护盾、复活与召唤区域；不虚构确定伤害数字。
- 硬控预览读取同一控制判定：展示含目标抵抗的主动技能概率，注明不含被动；Boss 免控时明确告知。冰霜护盾的随机/优先冰冻、护卫分担、现有护盾及暴露加伤分别提示。
- 实际结算保留伤害动作，额外明确显示“盾吸收 N”“抵抗状态”“免疫状态”，战况记录可追溯。概率未触发不伪装成免疫或抵抗。

`BattleDecision.plan()` 是只读计划：不调用游戏随机源，不试算伤害，不更改单位、冷却或资源。程序 API `SC.playerSelectSkill(index)` 仍保持原即时群体施放，供自动 AI 与测试场快捷按钮使用；玩家技能栏传入 `{preview:true}` 启用确认。

## 合击：自动时能发现机会，接管不等于消费

- 自动战斗只有满足阵容、能量、库存、控制、融合锁、次数及铺垫条件的配方才出现接管提示。当前成员能施放显示“合击就绪”，尚未到合法行动回合显示“合击条件已备”。
- 点击立即切手动。未提交的自动决策取消，已提交的敌方/技能动作正常完成；随后若行动者满足配方，就打开原合击确认窗口。若下一位不是合击成员或条件改变，留在手动并告知仍需相应成员行动。
- 接管、打开菜单、取消都不扣道具；只有确认真实施放才走原验证与原子扣款。AI 仍不会代玩家消耗触媒。
- 不可施放时显示具体角色缺多少能量、缺少触媒、未满足铺垫或等待对应成员等原因。离场/训练重置清除接管请求，旧回调不能在下一局打开菜单。

机会判断使用 `comboAvailability(...,{ignoreTurn:true})` 读取“条件已备”，仅略过当前回合归属；正式 `executeCombo` 不传此参数，回合限制与消费保护不变。

## 混沌元素：蓄力 → 应对 → 反击

第三波 Boss 第一阶段开场先预告混沌风暴，给玩家一轮准备时间。后续继续使用原三阶段行动表与冷却。70% / 35% 血量切相保留，但切相不会取消已预告的风暴。

| 应对 | 真实结果 | 反击窗口 |
| --- | --- | --- |
| 冰冻或麻痹成功，并在 Boss 行动入口打断蓄力 | 跳过风暴、触发原有硬控抗性 | 直接攻击伤害 +35% |
| 未打断，使用护盾/治疗应对风暴 | 实际扣盾/生命；风暴演出后暴露 | 直接攻击伤害 +20% |

- 两种暴露都持续到 Boss **下一次行动入口**，不是若干秒，因此倍速、暂停、合击长动画不会吃掉决策时间。控制跳过也算一次行动入口。
- 暴露通过 `dealDamage` 作用于正常技能、合击与召唤物直接攻击；持续伤害、固定伤害、反射不额外放大。Boss 死亡/离场不会残留至新局。
- 场内金色地面环、紧急提示和“战况”窗口共享同一暴露状态；释放分支的视觉在风暴命中时出现，不提前显示已承伤结果。
- 不保证控制必定成功。例如默认训练扎克的电磁脉冲：30% 主动麻痹 × (1 − 26.4% 抵抗) ≈ 22%；免控期间为 0。训练只备条件，不偷偷提高概率。
- HP、攻击基础值与控制抗性时长保持原值。该机制先作为一场 Boss 的可玩切片，未声称完成全阵容或全难度平衡。

界面沿用 v13：信息详情仍在独立战况窗口。选技能时把应对信息放入范围说明，不同时堆叠重复警告；Boss 场景固定额外预留操作区空间（桌面 216px / 小屏 296px，上限仍为战场 55%），避免底部合击被截断。预留值在回合状态切换中不变。

## 玩家测试步骤

刷新页面后，从标题页或城镇进入“功能测试场”，切“工具”。以下按钮会重建临时训练局，**没有正式奖励，不写存档**；测试中可收起面板观察完整战场。

1. **技能预览**：选择任一角色，点击“准备技能测试”。在战场技能栏选群攻/护盾，应出现作用范围和“确认施放”；先取消核对资源不变，再确认观察实际动作和目标变化。测试场右侧快捷技能按钮为直接单步施放，不弹预览。
2. **尝试打断**：工具页点击“Boss：尝试打断”。用扎克的“电磁脉冲”查看概率并施放；动作结束后，在“技能”页点“敌人行动一次”。若麻痹成功，应没有全队风暴伤害，并出现 +35% 核心暴露；未触发可重新点击场景按钮重试。
3. **护盾承伤**：工具页点击“Boss：护盾承伤”。用洛恩的“熔岩护盾”，动作结束后点“敌人行动一次”。观察实际护盾减少、风暴动作以及 +20% 暴露；回到洛恩或选择雷欧，打开契约合击并确认“熔日圣垒”，验证消耗 1 件临时触媒并发生真实攻击/护盾。若风暴使成员麻痹，按不可用原因先用艾琳“净化之光”，或用工具页的回满/净化按钮继续单独验收合击；测试场不会暗中免除负面状态。
4. **自动接管**：工具页点击“自动：合击接管”。点击场内“合击条件已备 · 接管”；如果敌人已出手，应先完成动作再开合击窗口。取消后保持手动且道具不变；再次准备并确认炎羽天陨，才消耗 1 件触媒及 60/40 能量。
5. **倍速与退出**：切 ×2 重复步骤 3/4，中途“暂停查看战况”后返回。动作不能重放、资源不能二次扣除；退出测试场后正式成长和库存保持原值。
