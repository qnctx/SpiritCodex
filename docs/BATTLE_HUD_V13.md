# v13：战斗操作栏与暂停战况

日期：2026-09-06。入口 `playable/spirit-codex.html`。本轮修改 HTML5 战斗界面和它使用的时钟，不改 Unity、角色数值、合击条件或正式存档。

后续增量见 [v14技能预览与 Boss 战术](BATTLE_DECISIONS_V14.md)：群体技能新增范围确认、自动合击可提示接管，Boss 战预留额外操作区；本页描述及验证数为 v13 历史基线。

## 为什么改

旧界面把观战、操作、详细情报放在同一块底部面板：敌人行动时仍显示大块空白、重复状态和不可用合击按钮。v13 按“现在是否需要玩家输入”切换界面。

| 战斗状态 | 当前展示 |
| --- | --- |
| 自动战斗、敌方行动、普通技能演出 | 底部仅一条当前行动提示，不显示不可操作的技能面板 |
| 轮到手动角色 | 展开此角色四技能、契约合击；满足满能条件时显示元素融合 |
| 选择单体目标 | 技能网格替换为目标提示、目标按钮和取消；也可直接点击战场中的合法单位 |
| 实战合击 | 只显示合击名称、演出阶段和跳过，不叠加普通回合提示 |
| 敌方蓄力 | 保留简短警告，点击可查看详细意图 |
| 查看详细信息 | 顶栏“战况”打开独立暂停窗口，分“战况 / 队伍 / 记录”三页 |

波次、回合移到顶栏；倍率和自动/手动常驻。“战斗设置”仍保留策略与退出，远征奖励、规则、行动序移到战况页，不占常规战斗操作区。自动状态想使用合击，先切手动，等待当前已提交动作完成、轮到己方角色再点“契约合击”；AI 仍不会代玩家消耗触媒。

战况页把敌人名和技能分成两行，行动序使用可读的“序号、角色名、当前/待行动/已行动”列表。队伍页展示生命、能量、护盾和状态剩余回合；记录页逐条显示最近六条记录。普通技能名称提亮，冷却技能仍不可点但名称不再被深色遮罩盖住。意图说明不再暗示能在战中随时换位（现有换阵入口属于波间整备）。

## 时序与布局约束

- Canvas 填满顶栏下的舞台；底部操作栏覆盖的是预留空地，不是角色。布局统一减去固定安全带（桌面176px、小屏248px，最多舞台高度55%），观察/手动/选目标之间不改变舞台尺寸或基础站位，避免面板收放导致人物和命中点跳动。
- 观察态实测底栏桌面55px、360px手机45px；正常手动操作栏约117px/209px。蓄力警告、较长提示会增加高度；极小测试场保留内部滚动。不能以“整个 Canvas 与操作栏绝不相交”为断言，应检查角色、合法目标和按钮不被覆盖。
- 战况窗口通过 `BattleClock.pause('battle-report')` 暂停游戏时间：包括动作、多段命中、血条表现、合击、天气与待执行自动决策。关闭或 Esc 仅恢复剩余时间；保留原自动模式和×1/×2，不重新执行规则或重复扣材料。
- 暂停支持独立所有者；连续开关、其他暂停所有者、退出和新开局均有清理。已打开融合、关键决策、波间整备时不再嵌套战况窗口。窗口使用原生 dialog 的焦点限制，关闭恢复原控件焦点。
- 测试场“工具”新增“暂停查看战况”，与正式入口共用实现；训练临时资源/无奖励/不写存档保持不变。
- 本轮沿用现有图片和动态系统，不新增立绘、视频或3D模型；暂停不改变技能命中规则。

## 最短测试步骤

1. 刷新 `playable/spirit-codex.html`，正常出征。保持“自动：开”，观察敌方行动时底部只有短提示，无大块空面板；×2 仍可切换。
2. 点“自动：开”切为“手动”。当前动作结束后，轮到己方才出现技能。点单体普攻→点敌人或下方目标按钮；选目标时可取消；出招后操作区自动收起，角色基础站位不跳。
3. 在普通技能或合击进行中点顶栏“战况”，等待几秒：动作、血条和天气均停住。切换三页查看详细信息，点“返回战斗”或 Esc 后接着播放，不从头再放。
4. 无需正式前提条件：标题页→功能测试场→任一合击按钮。播放中切“工具”→“暂停查看战况”，再返回；应只消耗一件临时触媒。手机可先收起测试面板放大战场。
5. 想测合击原条件：正式战斗切手动，在满足阵容、能量和铺垫时点“契约合击”；测试场可用“准备条件”后点底部同一入口。元素融合和契约合击的消耗仍按各自说明。
