# 功能测试场 v14

日期：2026-09-06。通过标题页或城镇的“功能测试场”进入；与正式战斗共用真实技能、合击、敌人AI和演出管线，不是录像播放器或数值预览。不在进行中的正式战斗内切入。

## 数据隔离

测试场在同页使用独立内存成长档、四人阵容、临时库存和随机源。进入前保存正式状态引用、阵容、设置、自动模式、战斗倍速、随机源及单位编号；退出先取消旧战斗、演出和回调，再恢复正式状态及倍速。战斗令牌只递增，不回滚，以免旧训练回调进入正式游戏。

训练中 `persistProgression` 仅允许内存提交，禁止真实存储写入；删除存档与远征奖励另有保护。临时道具的扣除仍走真实原子提交流程，但不会写入本机存档。训练不发放货币、经验或道具奖励；退出/刷新后训练资源丢弃，正式存档不变。测试场不是永久账号解锁或成长捷径。

## 操作步骤

1. 进入测试场后默认打开“合击”页，已准备炎羽天陨：四名主战、三件临时触媒、行动者60能量、伙伴40能量，以及灼烧中的存活训练靶。顶栏 `×1 / ×2` 随时切速；“技能 / 合击 / 工具”切页只改变可见面板，不重置战况。
2. 点击六种合击中的任一按钮，会重新准备该配方并**真实施放**。要分开观察扣费，先在“分步验证配方”选择配方、点击“准备条件”，再点“确认真实施放”。每次准备是新的训练局；真实施放只消耗一件临时道具及60/40能量，演出后的变化保留，不自动补回。
3. 切“技能”页，在“48 技能 · 独立动作演练”选择任意角色；未在场角色替换当前测试角色的主战槽。点“准备技能测试”补满能量/冷却、生成2,400生命靶子、准备伤员并腾空召唤位；艾琳额外准备倒下队友。“攻击目标”指定单体攻击或连锁首目标，“单体治疗目标”指定辅助技能受益队友。群体技能仍影响全部合法目标。可用原技能栏手选目标，也可用面板四个技能按钮。每测完再准备即可重测，并保留选择的敌人位置。耗能、冷却、伤害与治疗仍由正式引擎处理。详见 [v11技能动作](SKILL_PERFORMANCE_V11.md)。
4. “技能”页的“敌人行动一次”执行一名敌人的真实意图，完成后停回手动角色。“工具”页的“回满生命 / 能量 / 冷却”恢复并净化训练队伍，但不重置道具、合击次数或融合锁；“重置靶子”只恢复当前波敌人。完整重铺合击需回“合击”页再点“准备条件”。
5. “工具”页的“开启自动连战”恢复队伍并换用普通敌人生命，默认速攻策略使用真实AI连续推进三波；波间补给，完成或队伍倒下后继续下一轮训练，不领取奖励。可随时停止转回单步模式，当前已经结算的生命变化保留。自动AI不会消耗合击道具。
6. 手机面板位于战场上方并为其预留空间，可收起、展开和内部滚动；桌面面板为独立右侧栏。所有训练按钮使用至少14px文字与44px点击高度，不覆盖战场Canvas。完整合击演出期间可使用原有跳过按钮；测试面板“退出”会取消当前训练并恢复正式数据。
7. “工具”→“暂停查看战况”使用正式战斗同款战况窗口：技能/合击/环境和自动等待一起暂停。查看战况、队伍、记录后点“返回战斗”或 Esc 从原处继续，不回满资源、不重施技能、不改变倍速。底部只在手动回合显示指令，观察/演出时收起，详见 [v13战斗操作栏](BATTLE_HUD_V13.md)。
8. “工具”新增“Boss：尝试打断 / Boss：护盾承伤 / 自动：合击接管”三个预设。分别准备无免控蓄力 Boss、免控蓄力 Boss、条件就绪且敌方先行动的自动局。控制仍按真实概率，接管本身不扣道具。测试场快捷技能直接施放；要看范围和二次确认，使用战场原技能栏。详细顺序见 [v14玩家测试步骤](BATTLE_DECISIONS_V14.md#玩家测试步骤)。

六套条件分别为灼烧、减速、成员护盾、两名额外队员的低血/倒下、敌方负面、存活骷髅召唤物；配方成员始终存活且无冰冻/麻痹。所有效果使用 `SC.executeCombo`；测试场不另实现伤害或治疗公式。

## 接口与集成

- `window.openBattleLab()` / `closeBattleLab({screen?})`：同页进入及恢复，`SC.BattleLab.isActive()` 为存档保护依据。
- `prepareCombo(id)` / `castCombo(id)` / `prepareAndCast(id)`：准备真实训练局，以及预载完成后再次验证并实际施放；后两者返回Promise。退出、换配方或重置会取消旧的待加载施放。
- `selectCharacter(id)` / `useSkill(index)` / `enemyStep()` / `refill()` / `resetTargets()` / `setAutomatic(enabled)`：真实功能测试操作。
- `prepareSkillTest()` / `selectTestTarget('enemy'|'ally', uid)`：准备独立技能条件与指定快捷施放目标；演出过程中不允许叠加准备或更换锁定目标。
- `prepareBossScenario('interrupt'|'guard'|'opportunity')`：准备三种 v14 战术局；真实演出期间拒绝重建。控件为 `#battle-lab-scenario-interrupt` / `#battle-lab-scenario-guard` / `#battle-lab-scenario-opportunity`。
- `selectTab('skills'|'combos'|'tools')`：切测试类别。控件 `#battle-lab-tab-skills` / `#battle-lab-tab-combos` / `#battle-lab-tab-tools` 支持方向键；收起面板后 `#battle-lab-speed` 仍可操作。
- `#battle-lab-report` 调用 `BattleHUD.openReport()`；该窗口不属于训练状态，不会随训练快照恢复到正式战斗。离场关闭并释放自身暂停。
- 引擎在 `processTurn`、`completeWave`、`endBattle` 调用对应训练钩子；正常模式直接返回，不干预正式流程。`renderAll` 只通知面板刷新，不反向触发引擎渲染。
- `returnTown`、`resetGame`、从结算页进入成长等离场入口先恢复训练快照，不能把临时成长档留在正式页面。

稳定控件：`#battle-lab-panel`、`#battle-lab-close`、`#battle-lab-toggle`、`[data-lab-combo]`、`#battle-lab-prepare`、`#battle-lab-cast`、`#battle-lab-character`、`[data-lab-skill]`、`#battle-lab-skill-prepare`、`#battle-lab-enemy-target`、`#battle-lab-ally-target`、`#battle-lab-enemy`、`#battle-lab-refill`、`#battle-lab-targets`、`#battle-lab-auto`。
