# v12：战斗倍速、朝向规范与界面减负

日期：2026-09-06。入口仍是 `playable/spirit-codex.html`；本轮修改 HTML5 原型，不修改 Unity 工程或玩家存档。

后续 v13 已替换本文的“底部折叠详情”：现在是按状态切换的紧凑指令栏和独立暂停战况窗口，详见 [当前战斗界面与测试步骤](BATTLE_HUD_V13.md)。本文保留 v12 倍速/朝向设计和当时的验证记录。

## 本轮落地

- **×1 / ×2**：正式战斗顶栏与测试场顶栏可随时切换。当前页面内跨正式战斗保留速度，刷新默认 ×1；测试场退出恢复进入前速度，不污染正式设置。自动/手动与倍速相互独立。
- 普攻、48 个角色技能、敌方/召唤行动、回合等待、六种实战合击、命中反馈和环境余波共用游戏时钟。中途切速仅改变剩余时间，动画不从头开始。完整合击为 8.4 游戏秒，×2 为 4.2 实际秒；免费图鉴演练仍使用自身播放设置。
- 规则依旧只执行一次。倍速不增加伤害、不改变冷却回合/道具消耗/AI决策，不跳过玩家的目标选择、波间选择或关键决策弹窗。
- 风鹰原画朝左，现在在己方位置朝右迎敌。骷髅、英雄和敌人使用统一的原画朝向配置；动作中根据真实目标位置决定朝向。图片网格、嘴部/武器出口和受击高亮使用同一镜像矩阵，避免“本体向右、出招点留在左边”。合击双人施法的测量与绘制也共用目标方向。
- 粒子与飘字改为按游戏时间计算位移/寿命，避免帧数越多移动越快；血条更新保留头像节点，减少逐帧重建 DOM。仍是 2D Canvas 网格动画，**不是新增 3D 模型，也不承诺所有设备固定 60 FPS**。

## 界面检查及处理

| 检查项 | 处理 |
| --- | --- |
| 倍速、自动、策略、退出挤在一起 | 顶栏保留倍速和自动/手动，策略与退出移入“战斗设置”；展开占据正常布局，不覆盖战场 |
| 选择技能前先读意图、规则、队伍、日志 | 技能和合击入口前置；规则/意图/行动序放“战况详情”，队伍详情与日志单独折叠 |
| 收起信息可能漏看危险 | 首领/敌人蓄力在折叠标题显示警告，原有关键决策弹窗保留 |
| 元素融合与限定合击难以区分 | 元素融合标明“只耗能量 · 无需触媒”；契约合击标明“指定搭档 · 消耗触媒”和本局剩余次数 |
| 测试场六配方、四技能、恢复工具堆成长面板 | 拆成“技能 / 合击 / 工具”三页；顶栏倍速、收起、退出常驻；切页不重置战况 |
| 冷却/缺能按钮过度变暗，技能名字难辨 | 保持禁用与冷却逻辑，提升灰色名称/说明的可读性，不把不可用按钮伪装成可点 |
| 重做测试条件后总打第一个靶子 | 重建靶子时保留选定的敌人位置，UID 更新也不丢选择 |
| 城镇可玩功能与未实现建筑同权重 | 主区只显示出征、角色阁、进化塔、测试场；未开放的三建筑收进“后续建筑”，禁用点击并明确尚未开放 |
| 准备页/养成页是否要再拆 | 准备页已有编队、合击、远征、补给四页，养成已有独立进化塔，本轮保留，不把成长操作塞回战场 |

没有借此改动经济、招募、装备或角色平衡。尚未实现的建筑仍是未来内容，不宣称已开发完成。

## 最短手测路线

1. 刷新游戏（旧标签可按 Ctrl+F5）。标题页进入“战斗测试场”，默认是“合击”页。
2. 点击顶栏 `×1` 切到 `×2`，依次点六个合击按钮，无需准备正式角色/材料。每次应从聚能、显现、出招、命中到收尾完整走完，只消耗 1 件临时触媒。中途切回 ×1，应从当前位置继续，不重播或重复扣费。
3. 切“技能”，选择“琳·风羽”→“准备技能测试”→“技能 1 · 风鹰召唤”。风鹰落在己方召唤位，头朝右侧敌阵；小屏可收起测试栏放大战场。
4. “工具”→“开启自动连战”，观察风鹰和敌人真实行动。中途反复切 ×1 / ×2，检查出招、命中、血条、飘字一起变速；“停止自动连战”回到单步。
5. 切“技能”选艾拉，选择第二个攻击目标，再点“准备技能测试”。目标仍应是第二个；普攻命中第二个，箭雨则按规则命中全体。
6. 退出测试场。正式编队出征，顶栏切 ×2；“战斗设置”可调整自动策略/退出，技能区下方可展开战况和记录。训练中的速度与临时资源不带入正式档。
7. 返回城镇：主要入口均可用；“后续建筑”展开后明确为未开放，不能误点进假功能。

## 防止同类问题回归

- 新的战斗立绘必须在 `spirit-codex-battle-facing.js` 登记 `sourceFacing`（原画朝向）与源图归一化 `socket`（真实嘴/手/武器出口）。不要仅按“己方/敌方”猜素材朝向。
- `validateGameData()` 检查 12 英雄、2 召唤物、6 种敌人；缺少登记会报错。校验能防漏配置，**不能替代人工检查原画方向是否填写正确**。
- 姿态图表目前约定原画朝右，渲染时镜像；原图和姿态图各自按其源方向处理，不能叠加两次镜像。
- 新战斗定时器走 `scheduleBattle` / `BattleClock.schedule`；时间戳来自 `BattleClock.now`。Canvas 主入口接收原生 RAF 时间，只在入口转换一次。菜单、加载和免费预览不能误用战斗时钟。
- 退出、重置、训练换局取消已登记定时器，同时保留原有令牌/流程代号检查，防止迟到回调。
- 扩展测试需检查左右目标、网格与出口镜像一致、受击高亮方向、×1/×2 中途切换、多个命中点、取消与重复消耗、小屏控件可达。
