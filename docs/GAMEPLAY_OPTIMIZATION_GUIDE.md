# 《灵素图谱》玩法优化与成长策略攻略 v1.0

> 文档定位：先统一“游戏为什么好玩、玩家如何成长、阵容如何形成策略”，再进入代码实现。
>
> 适用基线：HTML5 三波回合制原型 + 团结引擎城镇/图谱/养成 MVP。
>
> 核心方向：一局约 5 分钟、有编队解题、波间构筑和分支进化的三波炼阵策略 RPG。

> 实施快照（网页版 v4.0，2026-09-05）：Slice A–D 已接通——4 名主战 + 最多 2 名替补、三波构筑、跨局成长和首批进化之外，战前现可配置剧情 / 标准 / 挑战三档难度、至多 3 个图谱契约、普通随机 / 每日固定种子，以及速攻 / 稳健 / 炼成三种自动策略。新增六套限定双人「契约合击」，通过战斗铺垫与持久消耗品提供清场、控场、护阵、救场、斩杀和召唤强化六条路线，详见 [合击攻略与试玩步骤](COMBO_ULTIMATES.md)。稳健会在首次合法普通融合或 Boss 蓄力时暂停并给出建议，炼成会自动施放合法的最高分普通融合；任何自动策略均不花合击道具。难度和契约共同提高灵墨、元素尘与角色精华，专精 XP 则只按难度折算、不会被契约放大。Lv.20 第二元素、Lv.30 最终节点、其余八名角色分支、地图长期解锁与 Unity 引擎规则同步仍未实现。

> v4.0 验证结果：合击专项 desktop + compact **38/38**；包含旧玩法的四视口全量回归 **296/296**。六张独立插画已接入真实施放，桌面和手机配方、弹窗及六种动态已逐张检查。对应图片提示词和来源见 [COMBO_ART_PROMPTS.md](COMBO_ART_PROMPTS.md)。

## 1. 先说结论

项目现在已经有 12 名角色、6 种元素、15 种双元素融合、4 种三元素融合、速度行动序、状态、召唤、复活和默认自动战斗。网页版 v3.9 已完成 Slice A–D：四人主战编队、敌方预告与阶段 Boss、阵式/灵方/营地单局构筑、分波复盘、三资源成长与首批八条机制进化，以及每日固定种子远征、契约难度和三套自动策略都已进入真实结算。

第一版“构筑—结算—成长—换规则再挑战”已经闭环，下一阶段仍有三个明确缺口：

1. **长期地图目标还不够**：每日种子、契约和难度已经能组织重复挑战，但还没有下一张地图、首通节点或长期地图解锁。
2. **进化覆盖仍是第一批**：H1 / H2 / W1 / A1 已各有两条真分支；其余八名角色、Lv.20 第二元素和 Lv.30 最终节点尚未落地。
3. **双端规则尚未统一**：网页版已形成回合制 A–D 基线，团结引擎仍有另一套实时战斗与旧成长逻辑，不能把两边视为同一实现。

后续应优先放大三个已有优势：

- **元素融合**：它应成为招牌决策，而不是玩家舍不得使用的消耗品。
- **前后排与角色定位**：坦克、治疗、控制、召唤必须在规则上有真实价值。
- **默认自动 + 关键手动接管**：自动负责执行阵容方案，玩家负责融合、打断、保命和 Boss 爆发窗口。

在这三点成立前，不建议优先扩展 PVP、公会、赛季、体力、多卡池和复杂装备词条。

## 2. 当前实施状态与硬问题

### 2.1 HTML5 战斗原型

- Slice A 已把出战规则收敛为必须填满的 2 前排 + 2 后排，另有最多 2 个替补槽；六个槽位可以选择、替换和互换，只有四名主战会创建初始战斗单位。
- 普攻、技能一、技能二、大招已采用 0 / 2 / 3 / 0 回合冷却；按钮显示剩余回合，手动和自动都复用同一合法性检查。
- 敌人已按可见意图和前排/后排/全体等规则选靶；冰霜守卫会加盾/护卫，风暴使者会加速，狼群会互相增伤。
- 混沌元素已在生命低于 70% 和 35% 时切相；全体技能先蓄力一回合，可被冰冻或麻痹打断，硬控成功后获得 2 个 Boss 行动回合的硬控抗性。
- 克制倍率已调整为 1.25 / 0.80、光暗互克 1.30；护盾累计封顶最大生命 40%；SR / SSR 运行时倍率收敛为 1.00 / 1.10。
- Slice B 已加入坚壁、疾风、炼成、召灵四种阵式；每种阵式同时具有收益与代价，并持续整次远征。
- 第一波后会从 8 个临时灵方中随机展示 3 个并选择 1 个；第二波后可三选一：全队回复 25%、指定存活角色 +40 能量、或交换一名主战与一名替补并保留双方生命、能量和冷却。
- 第一波、第二波和胜利分别锁定 30、65、100 灵尘；失败页会显示阵式、灵方、伤害/承伤与融合次数，并允许原阵重试或把替补换入最虚弱主战的位置后重试。
- 30 / 65 / 100 已改称“远征锁定”，只表示本局波次里程碑；Slice C 会另按 0 / 1 / 2 / 3 波原子结算三种可持久资源，避免把两套数值误认为同一种货币。
- 结算档位为：0 / 45 / 100 / 180 灵墨、0 / 8 / 17 / 25 元素尘、0 / 4 / 9 / 15 角色精华；只有初始四名主战和本局实际换入者获得对应熟练度，同一局不能重复领取。
- 图谱共鸣 1–30 每级为正式角色增加 2% 基础生命、攻击、防御；专精 1–5 由参战熟练度自动推进，技能强化 0–3 消耗元素尘。四名核心角色的灵启 I 在 Lv.10 开放，选择分支后必须再次确认才扣除角色精华。
- Slice D 已加入剧情 / 标准 / 挑战三档难度和 6 个可叠加契约；最多同时选择 3 个，敌方强度、治疗/护盾衰减、波初灼烧与技能冷却都进入实际结算。灵墨、元素尘和角色精华按难度与契约倍率结算；专精 XP 只按难度折算，契约不加成。
- 普通随机为每局创建新序列；每日挑战使用东八区日期生成固定种子。只有出征时的成长快照、阵容、规则与操作顺序全部一致，才可逐步复现灵方候选、行动抖动和战斗随机结果；结算成长后再次开局即使日期相同，也不承诺整局结果完全一致。
- 自动模式现在分为速攻、稳健、炼成：速攻偏重伤害与大招，稳健提前治疗/护盾并在关键节点暂停，炼成会在能量和协力条件满足时自动施放最高分融合；战中可以即时切换策略。
- 替补不会自动轮换；目前只允许在第二波后的营地选择中主动交换一次，第一波后或战斗回合内均不能换人。
- 当前 Boss HUD 的「韧性」显示的是硬控抗性剩余回合，并非可由伤害削减、受元素克制影响的独立韧性条。

### 2.2 团结引擎 MVP

- 二阶进化要求主角达到 Lv.10；当前图谱仅有推荐等级 1–3 的三张地图，而角色高于推荐等级 5 级后经验倍率为 0。正常循环会在约 Lv.8 后失去经验来源，使二阶进化不可达。
- 九宫格目前主要承担显示功能。普通怪物与 Boss 都直接攻击主角，招募队友缺少完整的生命、受击、倒下和仇恨模型，因此坦克、治疗、前后排暂时没有真实意义。
- HTML 是回合制角色技能与融合原型，团结引擎战斗则仍以实时计时自动攻击为主。若直接把养成继续接在实时版上，会同时维护两套互不一致的规则。

### 2.3 需要立即统一的规则

以 HTML5 版本作为近期战斗规则基线，团结引擎逐步统一到同一套：

- `BattleUnit`：主角、招募角色、召唤物和敌人都使用生命、能量、状态、速度和阵亡规则。
- `TurnState`：回合开始、选择行动、结算、回合结束和波间状态可复现。
- `SkillDefinition`：技能效果、冷却、目标和升级节点数据化。
- `Formation`：同一套 2 前排 + 2 后排规则，而不是只做视觉摆位。
- `Progression`：结算奖励、升级、技能强化和进化必须真实影响下一场战斗。

## 3. 游戏应该形成的三层循环

### 3.1 单回合：看懂威胁再行动

`观察敌方意图 → 选择技能和目标 → 制造/利用状态 → 留能量或爆发 → 承担结果`

每个关键回合至少应该出现下面一种取舍：

- 现在打断蓄力，还是为 Boss 下一阶段保留控制。
- 释放角色个人大招，还是把相同的满能量用于元素融合。
- 集火关键敌人，还是先维持治疗、护盾和净化。
- 追求克制伤害，还是保留更完整的职业结构。

### 3.2 单局三波：战斗中形成构筑

`查看敌情 → 编队/阵式 → 第一波 → 灵方三选一 → 第二波 → 休整/充能/换替补 → Boss → 战利品与复盘`

> 这是网页版 v3.9 的完整一局流程：战前难度/契约/种子/自动策略、四阵式、第一波临时灵方三选一、第二波营地恢复/指定充能/替补换位、Boss 与结算复盘均已接通。30 / 65 / 100 远征锁定仍是本局里程碑；结算页会同时展示按已通关波次和远征倍率实际写入本机存档的灵墨、元素尘和角色精华。

三波承担不同作用：

| 波次 | 玩法职责 | 玩家主要学习/决策 |
|---|---|---|
| 第一波 | 教学与蓄能 | 前后排、集火、状态和克制 |
| 第二波 | 阵容检查 | 处理护盾、加速、灼烧和控制链 |
| Boss | 综合解题 | 看意图、破韧、留能、融合和阶段转换 |

第一波后，从 8 个临时灵方池随机展示 3 个并选择 1 个：

| 灵方 | 本局效果摘要 |
|---|---|
| 余烬孢子 | 灼烧首次结算时，把 1 回合灼烧扩散给一个相邻敌人 |
| 澄泉引 | 治疗生命不高于 40% 的目标时额外净化 1 个负面状态；每目标每回合一次 |
| 棘甲铭文 | 护盾被击破时，按被击破护盾量的 35% 反伤攻击者 |
| 导电潮汐 | 水雷融合额外弹射 1 次，但会把该次融合触发的全队融合锁由 2 回合延长到 3 回合，并让施法者的炼成过载延长 1 回合 |
| 破绽追猎 | 对带负面状态的敌人造成伤害 +15% |
| 应激晶壳 | 单次承伤超过最大生命 25% 后获得 10% 最大生命护盾；每目标每回合一次 |
| 回响刻度 | 正式角色普攻命中后，最长的非大招剩余冷却 -1；每角色每回合一次 |
| 逆流蓄电池 | 正式角色打出元素克制伤害后获得 8 能量；每角色每回合一次 |

第二波后只允许三选一：

- 全队回复 25% 最大生命。
- 指定一名角色获得 40 能量。
- 与替补交换一名角色。

这些效果仅持续本次远征，提供重复游玩的变化，但不增加永久养成负担。普通随机每局生成新序列；每日挑战则按东八区日期生成固定种子。只有成长快照、阵容、远征规则和操作顺序一致时，才可逐步复现候选与战斗结果；结算引起的成长变化会改变后续推演，不能把每日种子理解为跨成长快照的完整战斗录像。

### 3.3 局外：每次战斗都推进一个目标

`获得灵墨/元素尘/角色精华 → 提升图谱等级 → 强化技能 → 选择进化分支 → 解锁第二元素 → 攻略新契约`

玩家每次胜利后必须能回答：“我现在可以升级什么，升级后下一局会有什么不同？”

## 4. 编队与阵型

### 4.1 队伍规则

- **标准出战为 4 人**：2 个前排位、2 个后排位；该规则已在网页版实现，未填满四个主战位不能出征。
- 第 5、6 人作为替补。替补不创建初始战斗单位，也不会自动行动或参与融合；第二波后若选择“替补换阵”，可指定一名主战和一名替补交换，双方保留生命、能量与冷却，离场角色随即停止行动和参与融合。
- 仅带 3 人的挑战编队仍是后续契约设计；当前网页版不允许三人出征，也尚无额外评分或材料奖励。
- 召唤物使用独立召唤位，最多同时存在 2 个，不占正式角色位，也不产生角色能量。

这已消除“六人同时行动一定最强”的问题，并让两名替补在第二波营地形成一次明确的决战前换人机会；其他时点的轮换仍未开放。

### 4.2 玩家可编辑站位

- 前排默认承受单体攻击，可触发援护、反击和护卫效果。
- 后排受到前排保护，但会被狙击、穿透、范围攻击或特殊意图针对。
- 坦克价值来自“替谁承担什么伤害”，不是单纯生命更高。
- 治疗和辅助需要实际可受伤的队友，不能只围绕主角生效。

### 4.3 战前阵式

网页版 v3.7 已实现四种有代价的阵式：

| 阵式 | 收益 | 代价 | 适合构筑 |
|---|---|---|---|
| 坚壁阵 | 前排减伤 12% | 后排速度 -8% | 坦克、治疗、持久战 |
| 疾风阵 | 每波首轮全队速度 +15% | 获得护盾量 -15% | 控制、爆发、抢先手 |
| 炼成阵 | 本次远征首次融合的协力能量消耗减半 | 正式角色获得能量 -10% | 多元素融合队 |
| 召灵阵 | 召唤物伤害 +20%、持续时间 +1 回合 | 正式角色普攻伤害 -10% | 风/暗召唤队 |

阵式只改变打法，不提供无条件的永久增益。

## 5. 技能、能量与融合

### 5.1 技能结构

每名角色继续保留四个动作，但要保证每个动作都有使用场景：

| 动作 | 规则 | 用途 |
|---|---|---|
| 普攻 | 无冷却，获得 20 能量 | 填充回合、蓄能 |
| 技能一 | 冷却 2 回合 | 角色的高频核心动作 |
| 技能二 | 冷却 3 回合 | 控制、保护或高价值输出 |
| 大招 | 消耗 100 能量 | 角色专精的强力效果 |

攻击型技能不应全部只是不同倍率；至少有目标数量、破盾、斩杀、状态联动或位置规则中的一项区别。

### 5.2 大招和融合共用决策资源

- 角色满 100 能量时，可以释放个人大招，也可以发起融合，不能两者都用。
- 双元素融合消耗发起者 100 能量，协力角色额外消耗少量能量或一层元素共鸣。
- 三元素融合需要进化解锁，且每个 Boss 区域最多使用一次。
- 任意融合后，全队获得 2 回合“炼成过载”，过载期间不能再次融合。
- 局外“融合核心”不再作为每次施放都会消耗的稀有道具；它改为解锁配方、提升每局融合容量或改变配方分支，避免玩家因囤积而不使用招牌系统。

设计原则：**大招强在角色专精，融合强在临场适配。**

### 5.3 元素与数值建议

下列第一轮数值收敛已在网页版 Slice A 实施：

- 循环克制为 1.25 / 0.80，保留针对编队价值但不让带错元素直接失败；光暗互克均为 1.30。
- 普通角色/敌方护盾技能为目标最大生命 20%，护盾大招为 35%，融合护盾为 25% 或 40%；同一单位护盾累计不超过最大生命 40%。
- Boss 被硬控一次后，获得 2 个自身行动回合的硬控抗性；减速、破防等软控仍可生效。
- 稀有度倍率为 N 0.88 / R 0.94 / SR 1.00 / SSR 1.10；当前正式角色只使用 SR / SSR，纯倍率差为 10%，主要强度仍应来自机制与构筑位置。

## 6. 自动战斗应该怎样设计

默认进入战斗时保持自动，玩家可以随时切换手动；自动不是“跳过玩法”，而是执行玩家设置好的战术。

> 网页版 v3.9 已接通 Slice D 的第一版：三个预设复用手动模式的技能合法性、目标与结算管线，战前可选并能在战中切换。自动决策不会绕过冷却、能量或融合协力成本。

### 6.1 三个自动预设

| 预设 | 行为 |
|---|---|
| 速攻 | 提高伤害技能和满能大招优先级，降低支援权重，不主动融合 |
| 稳健（默认） | 更早治疗与护盾；首次合法融合或 Boss 蓄力时暂停并给出推荐 |
| 炼成 | 能量与协力角色条件满足时，自动施放当前评分最高的合法融合 |

### 6.2 可配置条件

v3.9 先把复杂配置收敛为三个可理解预设，尚未单独开放下列细粒度开关：

- 治疗阈值：40% / 60% / 80%。
- Boss 前是否保留大招。
- 是否允许自动融合，以及首选融合配方。
- 优先目标：克制目标 / 残血 / 正在蓄力 / 玩家标记。

### 6.3 关键决策暂停

稳健策略会在本局首次出现合法融合，或 Boss 显示蓄力时短暂停顿并给出推荐：

`推荐：火 + 雷「雷火炼狱」 / 扎克个人大招 / 继续蓄能`

玩家可以“采用推荐”“切换手动”或“继续自动”。弹窗是强制决策点，关闭前不会让后台自动逻辑偷跑；这样既适合默认自动的轻操作体验，也给高难战斗留下手动上限。队友濒死暂停与可配置阈值仍属于下一轮细化。

## 7. 升级与资源

### 7.1 共享图谱等级

建议把角色重复练级改为“图谱共鸣等级 1–30”：

- 全角色共享基础等级，新获得角色可以立即进入当前队伍。
- 每级只提供约 1.5%–2% 的基础生命、攻击和防御成长。
- 1–30 级总数值成长控制在约 50%–60%，关卡机制与构筑仍然重要。
- 敌人使用固定等级或章节区间，不做完全动态同步，让成长确实带来变强感。

### 7.2 角色专精

每名角色另有 1–5 级专精，不重复堆基础属性：

- 专精 2、4：小幅数值或冷却优化。
- 专精 3、5：改变技能机制，例如增加目标、触发联动、改变状态或 AI 条件。
- v3.8 的专精进度来自角色实际参加远征；初始四名主战与本局换入者会按已通关波次获得熟练度，未参战替补不获得。角色精华直接提升专精可作为后续扩展，但当前没有该消费入口。

### 7.3 MVP 只保留三种核心资源

| 资源 | 主要用途 |
|---|---|
| 灵墨 | 提升共享图谱等级 |
| 元素尘 | 当前用于技能 0–3 强化；后续可扩展元素技能节点 |
| 角色精华 | 当前用于 Lv.10 分支解锁与切换；后续用于最终节点 |

角色专精当前由实际参战获得的熟练度自动推进，不是第四种可消费货币，也不会手动扣除角色精华。金币可作为界面上的通用计价资源保留，但不应再同时堆叠经验药、突破石、技能页、大脑进化液、多个催化剂和多个品质核心。第一版的资源应做到玩家一眼知道“从哪里来、用在哪里”。

### 7.4 成长节奏目标

- 第一局胜利后即可完成一次升级。
- 20–30 分钟出现第一次明显的技能强化。
- 30–45 分钟完成第一个进化分支选择。
- 3–5 小时可让一支四人核心队进入第二阶段进化。
- 普通关不要求同一节点重复刷超过 3 次。

## 9. 敌人与 Boss 如何产生策略

网页版 Slice A 已显示每个存活敌人的下一行动与目标，例如“攻击前排”“后排突袭”“全体蓄力”“全体护盾/加速”。普通冷却技能按固定模式选择，实际目标在意图生成时锁定；控制、死亡或波次变化会刷新意图。

| 敌人 | 独特机制 | 主要反制 |
|---|---|---|
| 暗影狼 | 两只同时存活时互相增伤 | 集火击杀一只 |
| 暗影蝠 | 预告突袭后排，并可施加诅咒 | 后排保护、致盲、提前治疗 |
| 炎魔兵 | 攻击前排，并可附加 2 回合灼烧 | 护盾、净化、优先击杀 |
| 冰霜守卫 | 为同伴提供护卫与护盾 | 雷系破盾、破防、换目标 |
| 风暴使者 | 突袭后排，并可使敌方全体加速 25% | 火系克制、减速、硬控 |
| 混沌元素 Boss | 70%/35% 生命切相，预告并蓄力混沌风暴 | 硬控打断、预先护盾、保留净化和融合 |

网页版已实现的 Boss 规则：

- 生命低于 70% 与 35% 时分别切换到第二、第三阶段，改变技能模式并获得速度或攻击增幅。
- 「混沌风暴」蓄力一回合后攻击全体；蓄力期间成功施加冰冻或麻痹，会在 Boss 行动时打断。
- 任意一次硬控成功后获得 2 个 Boss 行动回合的硬控抗性，期间新的冰冻/麻痹无效；软控仍可生效。
- HUD 显示当前阶段、蓄力状态和控制抗性剩余回合。

独立可削减韧性、元素调谐/克制破韧，以及 Boss 召唤或护盾阶段尚未实现，保留为后续扩展，不应按当前玩法向玩家承诺。

## 10. 五套可玩的阵容攻略

> 当前可直接验证的是每套阵容的四名主战、技能冷却、前后排选靶、元素融合、Boss 蓄力打断，以及第二波营地的一次主战/替补换位。换人不是自动轮换，且选择换人就会放弃本次营地的恢复或充能；独立破韧和 Boss 元素调谐仍属后续目标。

### 10.1 雷火先手爆发

**阵容**：洛恩 H2 + 艾拉 H1 + 扎克 T1 + 赛巴斯 A2

**替补**：汐 W1、雷欧 L2

**打法**：赛巴斯加速，洛恩破防，扎克集中爆发，艾拉用灼烧清场；核心融合为火雷与风雷。

**手动时机**：第二波结束前留住扎克能量；Boss 蓄力时先用硬控打断，再决定释放个人大招或雷火融合。

**弱点**：续航弱，拖入长线或被先手控制后容易崩盘。

### 10.2 潮光不灭

**阵容**：亚瑟 W2 + 雷欧 L2 + 汐 W1 + 艾琳 L1

**替补**：奈娜 T2、赛巴斯 A2

**打法**：减速、致盲、治疗、净化和复活组成稳定防线，以水光“治疗雨”维持长线。

**手动时机**：不要在普通伤害后立刻交净化；等 Boss 的关键控制落地再使用。

**弱点**：击杀速度慢，害怕随回合强化或进入狂暴的敌人。

### 10.3 暗风召灵

**阵容**：卡尔 D2 + 薇洛 D1 + 琳 A1 + 赛巴斯 A2

**替补**：艾琳 L1、洛恩 H2

**打法**：骷髅承伤、风鹰高速攻击，赛巴斯提供速度与保护，薇洛在暗风破防后收割。

**手动时机**：敌人预告范围清场时不要继续召唤，先打断或用当前主战的保护技能应对。

**弱点**：害怕范围光伤、驱散召唤和快速切后排。

### 10.4 四相破阵

**阵容**：洛恩 H2 + 亚瑟 W2 + 奈娜 T2 + 赛巴斯 A2

**替补**：艾琳 L1、艾拉 H1

**打法**：火、水、雷、风覆盖第二波的克制环，可灵活使用蒸汽、电磁洪流和风暴雷霆。

**手动时机**：根据 Boss 当前阶段与下一意图切换融合，不要固定重复同一配方。

**弱点**：缺少专职治疗；第二波营地可以回复或把替补艾琳换入，但两者不能同时选择，需要根据当前血线提前取舍。

### 10.5 圣焰裁决

**阵容**：洛恩 H2 + 雷欧 L2 + 艾拉 H1 + 艾琳 L1

**替补**：汐 W1、薇洛 D1

**打法**：火系叠加负面，雷欧处理受负面影响的目标，火光融合对暗系波次和 Boss 强势。

**手动时机**：光暗互克会让队伍承受高伤，应在 Boss 爆发前预先护盾而不是受伤后补救。

**弱点**：缺少稳定速度控制，对高速敌人容错较低。

## 11. 失败、复盘与重复游玩

### 11.1 v3.8 已实现的本局锁定、持久结算与重试

- 清完第一波把本局锁定灵尘设为 30，清完第二波设为 65，击败 Boss 后设为 100；这些是确定数值，不是百分比。
- 失败结算保留已通关波次对应的锁定值，并显示本局阵式、已选灵方、造成伤害、承受伤害、融合次数和基于主战存活情况的简短建议。
- “原阵容重试”会用当前战前编队开始一局新的远征；“换入替补并重试”会把第一名替补换入本局结束时生命比例最低的主战槽位，再重新开始。
- 远征锁定本身不作为货币；结束远征时会按已通关 0 / 1 / 2 / 3 波，分别以 0 / 45 / 100 / 180 灵墨、0 / 8 / 17 / 25 元素尘、0 / 4 / 9 / 15 角色精华，以及 0 / 1 / 2 / 3 专精 XP 为基础档位。v3.9 对三种货币应用远征奖励倍率；专精 XP 独立按难度系数折算，不吃契约加成。
- 领取和消费使用“先写入本机存档、成功后再提交内存”的原子路径；同一局重复调用结算不会重复入账，原阵重试、换替补重试、返回标题也不会清除跨局成长。

仍属后续设计：账号/云端存档、首通奖励、连续失败援助，以及死亡来源/未处理意图的更细日志。

### 11.2 第一阶段的低成本可重玩内容

网页版 v3.9 已先做“图谱契约”，不立即做完整 Roguelike：

| 契约 | 实际规则 | 三种货币契约加成 |
|---|---|---:|
| 铁壁敌阵 | 敌人最大生命 +25% | +15% |
| 猎杀时钟 | 敌人攻击 +10%、速度 +18% | +20% |
| 枯竭灵泉 | 我方受到的治疗量 -30% | +8% |
| 破碎晶壳 | 我方获得的护盾量 -30% | +8% |
| 余烬地脉 | 每波开始时，正式角色获得 2 回合灼烧 | +18% |
| 封术刻印 | 非普攻、非大招技能的基础冷却 +1 | +12% |

玩家可同时勾选 0–3 个契约。三档难度为剧情（敌方属性降低、货币奖励 ×0.8、契约加成只计 25%）、标准（基准、货币奖励 ×1.0、契约加成计 100%）和挑战（敌方生命 ×1.25、攻击 ×1.20、防御 ×1.10、速度 ×1.08，货币奖励 ×1.35、契约加成计 100%）。灵墨、元素尘和角色精华的最终倍率为：

`货币倍率 = 难度倍率 ×（1 + 契约加成总和 × 契约计入系数）`

其中剧情的契约计入系数为 0.25，标准 / 挑战为 1.0，最后分别对三种货币四舍五入。专精 XP 不使用该货币倍率，而以已通关波次的 0 / 1 / 2 / 3 为基础，分别乘剧情 2/3、标准 1、挑战 4/3 后四舍五入（只要已通关至少一波，最低为 1）；完整三波最终为剧情 2、标准 3、挑战 4，契约不会增加专精 XP。30 / 65 / 100 远征锁定仍只是单局里程碑，不随任何倍率变化。

普通随机每次出征创建新种子；每日挑战以东八区日期为种子键。只有出征时的成长快照、阵容、难度、契约和操作顺序全部一致，才能按步骤复现灵方候选与战斗随机序列；若上一局结算后发生升级、专精、技能强化或进化变化，则不保证重开整局仍完全相同。

## 12. 推荐开发顺序

### Slice A：让战斗有真实选择（网页版已完成战斗内范围）

**当前实施结果（2026-09-05）**

- 4 名主战必须填满 2 前排 + 2 后排；最多 2 名替补可在战前选择、替换和互换，只有四名主战进入战斗。
- 普攻 / 技能一 / 技能二 / 大招采用 0 / 2 / 3 / 0 回合冷却，手动与自动共用合法性检查。
- 敌方意图、前后排/全体目标规则、敌方护盾/护卫/加速和狼群增伤已进入实际结算。
- 混沌 Boss 在 70% / 35% 生命阈值两次切相；一回合蓄力可被硬控打断，硬控成功后获得 2 个自身行动回合的抗性。
- 元素克制、光暗互克、护盾上限与稀有度倍率已按 5.3 节数值实施。
- 独立可削减韧性与元素调谐不在本切片完成范围；它们仍归后续 Boss 扩展。替补波间换入已在 Slice B 以“第二波营地三选一”的受限形式接通。

**内容**

- 统一回合制战斗单位与行动状态。
- 修正护盾、元素克制、稀有度差距和 Boss 控制递减。
- 普攻 + 两个冷却技能 + 大招。
- 4 人在场 + 2 替补，可编辑 2 前排 / 2 后排。
- 敌人意图与两次阶段转换（共三阶段）的混沌 Boss。

**验收 / 测试步骤**

1. 用同一角色连续操作 6 回合，确认至少会使用 3 种不同动作，不能无成本重复最强技能。
2. 分别把坦克放前排和后排，验证敌方目标、援护与承伤结果确实不同。
3. 使用控制队连续控制 Boss，验证首次生效后出现 2 回合硬控抗性。
4. 用五套示例阵容打普通难度，至少四套在同养成下可通关，成功率差距不超过约 15 个百分点。
5. 检查 360px 宽度与常见横屏分辨率，中文不裁切、按钮不遮挡且可以点击。

**该切片当时的验证状态：** 两个 JavaScript 文件均通过 `node --check`，差异通过 `git diff --check`；Playwright 完整回归 **136/136**，覆盖 desktop、tablet、mobile、compact 四类视口。

### Slice B：接通一局三波构筑（网页版 v3.7 已完成）

**当前实施结果（2026-09-05）**

- 战前可选坚壁、疾风、炼成、召灵四种阵式；效果和代价持续整次远征。
- 临时灵方池共 8 个；第一波结束后随机展示 3 个并选择 1 个，效果只在本次远征内触发。
- 第二波结束后从灵泉休整、聚能冥想、替补换阵中选择 1 项：全队回复 25%、指定存活角色 +40 能量，或交换一名主战与替补并保留双方生命/能量/冷却。
- 第一波、第二波和胜利分别显示 30、65、100 锁定灵尘；失败结算可查看路线与战斗数据，并原阵重试或换入替补重试。
- 本切片当时只定义远征锁定；Slice C 已在其后接入独立的三资源持久结算，Slice D 再接入普通随机与每日固定种子。

**内容**

- 第一波后的灵方三选一。
- 第二波后的恢复 / 充能 / 换人。
- 四种战前阵式。
- 30 / 65 / 100 分波锁定值、失败复盘和换替补重试。

**验收 / 测试步骤**

1. 验证生命、能量、冷却、召唤限制和临时灵方正确跨波继承。
2. 分别选择三个波间选项，确认恢复、指定充能和换位在第三波产生可观察差异；可分别从同一成长存档快照开始，并使用 Slice D 的每日固定种子控制其他随机变量。

## 14. 第一版完整玩家流程（网页版 Slice A–D 已闭环）

> 当前网页版 v3.9 已完成第 1–9 步，并接通约 35 分钟首次灵启 I、每日种子、三档难度、六契约和三种自动战术；下一张地图、Lv.20/30 进化与长期地图解锁仍未实现。

1. 进入城镇，领取新手四人队。
2. 打开图谱，查看第一关敌方元素和主要意图。
3. 调整 2 前排 / 2 后排、阵式、难度、契约、随机模式与自动预设，进入三波战斗。
4. 默认自动执行普攻与常规技能；遇到融合、Boss 蓄力或濒死时可手动接管。
5. 第一波选择临时灵方，第二波选择恢复、充能或替补交换。
6. 击败 Boss，看到 100 远征锁定、本局路线/伤害复盘，以及实际入账的灵墨、元素尘和角色精华。
7. 返回城镇完成图谱升级或角色专精，真实改变下一局技能或属性。

9. 通关章节后，以不同阵容、自动战术和图谱契约继续挑战。

这条链路每一环都能回到下一场战斗，形成真正连接的 MVP：

`看敌情 → 组队 → 战斗构筑 → 锁定/结算奖励 → 升级/进化 → 换策略挑战更高难度`

目前真正闭环的是“看敌情 → 4+2 编队、阵式与远征规则 → 三波战斗及两次波间选择 → 自动策略/关键手动接管 → 复盘与倍率化三资源入账 → 图谱/专精/技能/首次进化 → 以契约或相同成长快照下的每日种子验证下一局”；地图解锁、其余角色分支与 Lv.20/30 仍待实现。
