# v11：48 个角色技能的独立动作

日期：2026-09-06。覆盖 HTML5 可玩版的 12 位角色 × 4 技能；正式战斗、自动战斗和功能测试场共用同一条演出管线。六种限定合击保留 v10 的实战画布演出。

## 设计与实现

不再根据倍率或“弓箭 / 近战 / 法术”三个通用类别决定表现。每个技能有明确的角色姿态、武器出口、攻击形态、目标规则与时间轴；不调整技能数值来冒充差异。

人物使用既有四姿态画稿，加局部网格关节变形、接敌位移和朝向。武器锚点通过同一组网格三角形计算，不能用旧位置发射技能。近战到真实目标身前出招后返回原位；远程从当前武器位置发出；箭雨、陨石、雷柱和圣剑从目标上空落下。治疗、护盾与召唤依据真实友方单位或召唤位展示，不朝敌人伪造伤害。

火焰、流星、烟尘、刀光和命中采用已有美术笔刷图集的透明化、着色、旋转与分层运动，叠加定向粒子；没有新增黑底图片板。地面法阵保持地面透视，不随旋转立起来挡住角色。连锁起点跟随上一名敌人实际绘制的受击位置。

普攻约 0.9 秒，战术技能 1.9–3.1 秒，大招 4–4.6 秒。三轮箭雨、四段暗影之舞使用引擎记录的每次实际伤害，按段更新视觉血量和受击反馈。连锁闪电按实际伤害顺序连接，不固定从第一个敌人开始。满血治疗仍有指向受益队友的动作，但不伪造治疗数值。

这是现有二维美术的实时动画与程序特效，不是真正三维骨骼模型，也不是预录视频。动作模块只读取规则结算；伤害、治疗、冷却、耗能、复活和召唤均仍由正式引擎执行一次。减少动态模式保持安静短切换；退出或重置会取消旧动作和延迟飘字。

## 最短测试路线

1. 刷新 `playable/spirit-codex.html`，标题页或城镇进入 **功能测试场**。
2. 在 **48 技能 · 独立动作演练** 选择 **艾拉·炎棘**，点 **准备技能测试**。自动补满能量、重置冷却、放置 2,400 生命训练靶，准备伤员并清空召唤位；不会修改正式存档。
3. 在 **攻击目标** 选择 **2 · 暗影狼**，先测普攻和烈焰穿刺：只应攻击选定的靶子，角色拉弦/蓄力与弹道应有区别。每测一个技能，再点一次 **准备技能测试** 可立即重测；重新生成靶子后，再选择要测试的攻击目标。
4. 测箭雨和陨落：前者应举弓后从上空分三轮落箭并逐段掉血；后者先引导火核，再有流星落向敌阵。它们是群体技能，因此仍命中全部合法敌人，而非只攻击下拉框选中的一个。
5. 切 **洛恩·炉火** 测冲锋，切 **奈娜·闪电** 测连锁闪电，切 **薇洛·暗舞** 测四段近战。更换敌方目标验证起手目标确实变化。
6. 切治疗角色后，在 **单体治疗目标** 指定伤员；测试治疗/净化。该下拉框只指定单体技能的队友，群体治疗/净化仍影响全队。艾琳的准备条件额外含倒下队友，便于测试神圣洗礼。召唤角色的准备条件会腾空召唤位。
7. 收起面板可扩大观察区域；演出中不能叠加施放。完成后点 **退出**，正式阵容、物品和存档应保持不变。

合击仍可直接使用六种一键真实施放按钮；无需为角色技能测试重新铺合击条件。
