## 一、美术风格定义

### 1.1 整体定位

**关键词**：神秘、炼金、元素、奥术、幻想

- **色调**：暗调为基础（深紫/深蓝/黑色），角色立绘用明亮色彩点缀
- **角色**：二次元精美立绘比例（头身比约6-7头身），但不做过于萌系的处理
- **背景**：暗黑幻想风，雾气废墟、古老遗迹、炼金实验室
- **UI**：炼金术风格边框（黄铜/古铜质感）+ 现代扁平化信息布局
- **元素视觉**：每种元素有强烈的色彩标识系统

### 1.2 色彩体系（元素配色）

| 元素 | 主色调 | 辅助色 | 光效色 |
|------|--------|--------|--------|
| 🔥 火 | `#E84530` 熔岩红 | `#FF8C42` 橙黄 | `#FFE66D` 金光 |
| 💧 水 | `#2E86AB` 深海蓝 | `#7EC8E3` 浅蓝 | `#A0E7E5` 冰白 |
| 🌪 风 | `#90BE6D` 草绿 | `#B8E994` 浅绿 | `#F0F8E8` 银白 |
| ⚡ 雷 | `#5B5EA6` 暗紫 | `#9B59B6` 亮紫 | `#F9CA24` 电金 |
| 🌑 暗 | `#2C2C34` 墨黑 | `#4A4A5C` 暗灰 | `#9B59B6` 幽紫 |
| ☀️ 光 | `#F7DC6F` 金黄 | `#F8EBC8` 暖白 | `#FFFFFF` 纯白 |

### 1.3 角色立绘规范

- **尺寸**：立绘 1080×1920 px（竖屏卡牌格式）  
- **风格**：厚涂二次元 + 轻微写实阴影  
- **角色站姿**：正面或3/4角度，双手自然下垂  
- **背景**：透明或统一纯色底（便于UI裁剪）  
- **重要元素**：每个角色必须有明显的**元素标识**（如肩部/胸口/武器上的元素符号）

## 五、AI 工具推荐

| 工具 | 用途 | 建议 |
|------|------|------|
| **Midjourney** | 角色立绘、概念图 | 二次元风格效果好，Niji模式 |
| **Stable Diffusion** | 批量生成、LoRA训练 | 本地免费，需GPU |
| **Leonardo.ai** | 角色立绘 | 有预训练动漫模型 |
| **DALL-E 3** | 快速概念验证 | 质量一般，用于初稿 |

### 推荐工作流

```
Phase 1: 用 Midjourney 生成 12 个角色立绘（每元素2个）
Phase 2: 选最喜欢的方向，精修或再生成
Phase 3: 用 Stable Diffusion 训练 LoRA，保持风格统一
Phase 4: LoRA 批量生成剩余角色
```
